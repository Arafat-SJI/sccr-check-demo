# Features

Feature briefs for the Horologe Genève storefront.

## Implemented

| Feature | Route | Source |
|---------|-------|--------|
| Home / maison landing | `/` | Stitch Home screen |
| Client login portal | `/login` | Stitch Client Login |
| Registration / membership | `/register` | Stitch Sign Up |
| Product detail (PDP) | `/product` | Stitch Product — Chronographe No. 04 |
| Shared navigation chrome | all | Header + Footer components |

## Writing a feature brief

Add `docs/features/<feature-name>.md` with:

1. Goal
2. User flow
3. Screens / routes
4. Acceptance criteria
5. Out of scope
